# Bop ERP

Modular industrial distribution ERP extension designed to replace Epicor Prophet 21 workflows while keeping ERPNext and Frappe upstream intact.

## Key Principles
1. **Zero Core Modifications**: Upstream ERPNext/Frappe source code is never edited.
2. **Local-First & Cloud-Portable**: Same codebase runs locally in Docker and on production cloud infrastructure (AWS) without source forks.
3. **Omnichannel & Multi-Store**: Designed for industrial distribution with unified inventory and channel-level attribution.
4. **Prophet 21 Feature Parity**: P21 customer hierarchy, replenishment workbench, subcontracting, and mass SKU management.

## Technical Details
- **App Name**: `bop_erp`
- **Frappe Version**: 16.x Compatible
